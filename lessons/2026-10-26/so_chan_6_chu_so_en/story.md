| Tiếng Việt | English |
|---|---|
| Số có 6 chữ số khác nhau / là số chẵn | 6 digits, all different / and even |
| là số lẻ (thử sức) | and odd |
| chẵn / ≠ 0 | even / ≠ 0 |
| Số 0 không đứng đầu | 0 can't go first |
| Có bao nhiêu số? | How many numbers? |
| Hàng đơn vị: 0, 2, 4, 6, 8 / Hàng đầu: khác 0 | Ones digit: 0, 2, 4, 6, 8 / First digit: not 0 |
| Đơn vị là 0 / Đơn vị là 2, 4, 6, 8 | Ones digit is 0 / Ones digit is 2, 4, 6, 8 |
| cách | ways (1 way) |
| Hàng đầu: từ 1 đến 9 | First digit: 1 to 9 |
